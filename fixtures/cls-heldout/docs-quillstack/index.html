Configuring webhooks

Webhooks tell your server when a document finishes rendering, fails, or is opened by its recipient, so you never have to poll.

Before you startYou need an API key with the events:write scope and an HTTPS endpoint that answers within ten seconds.

Create an endpoint

Register the URL that should receive events. Quillstack sends a signed POST for every event type you subscribe to.

curl https://api.quillstack.example/v4/webhooks \
  -H "Authorization: Bearer $QUILL_KEY" \
  -d url="https://example.org/hooks/quill" \
  -d events[]="document.rendered" \
  -d events[]="document.failed"

Parameters

NameTypeDescription
urlstringHTTPS endpoint that receives the events. Required.
eventsstring[]Event types to deliver. Defaults to every type.
secretstringUsed to sign each delivery. Generated when omitted.
pausedbooleanCreate the endpoint without delivering to it yet.

How delivery works

Each delivery is attempted up to eight times over twenty-four hours. An endpoint that fails for three days in a row is paused and the account owners are emailed.

Write the handler

app.post('/hooks/quill', express.raw({ type: 'application/json' }), (req, res) => {
  const event = quill.webhooks.verify(req.body, req.get('Quill-Signature'), secret);
  queue.add(event.type, event.data);
  res.sendStatus(204);
});

Answer with a 2xx status as soon as you have stored the event, and do the work afterwards.
