Troubleshooting builds

The six problems that account for most failed or slow builds, and how to tell them apart. Select a question to see the answer.

Common problems

Kiln 2.8 needs Node 20 or newer. Check with node --version and upgrade, or pin Kiln to the 2.6 line.

The incremental cache keys pages by their front matter and template, not by included partials. Editing a partial does not invalidate the pages that use it unless you declare the dependency.

Clear the cache once to confirm that this is the cause:

kiln build --no-cache

Then list the partial under dependsOn in the page's front matter, or turn on trackIncludes in kiln.config.js (slower, but always correct).

Collections are held in memory unless you stream them. Set stream: true on any collection with more than ten thousand entries.

Resized images are cached in .kiln/images. Persist that directory between CI runs.

Set baseUrl to the path your host serves the site from, and use the url filter in templates.

On network drives and in some containers, file events are not delivered. Start the server with --poll.
