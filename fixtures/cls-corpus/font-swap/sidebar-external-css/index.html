Planning a journey

The side navigation is as wide as its longest label. Its labels are set in a web font that is declared in a separate stylesheet, fonts.css.

When the font arrives the labels become about twice as wide, the navigation grows with them, and this whole column is pushed to the right.

The navigation keeps its seven lines, so the shift on this page is horizontal. Text in this column re-wraps because the column is now narrower.

A day ticket covers all buses and the harbour ferry. Children under eleven travel free with an adult, and dogs travel free at any time.
