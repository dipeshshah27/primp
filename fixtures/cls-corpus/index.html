reglet layout-shift corpus

Static pages whose layout shifts are deterministic: every late resource is served through /delay/<ms>/<path>, which answers a fixed number of milliseconds after the request. Each page has an expected.json beside it with the cause, the culprit, its source line and the elements that move.

Labels were measured in headless Chromium at 1280x800. See README.md for the label format and for what was learned about the Layout Instability API.
