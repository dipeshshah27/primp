Things that move without shifting layout

Platform change: the 08:15 to the south quay leaves from the east steps.
This card is moved 40px right and 60px down with a transform when a class is added 700 ms after load.

Every movement on this page is a CSS transform: a keyframe animation that slides the ticker in, a looping animation on the square, and a transition on the card.

Transforms change where an element is painted, not where it is laid out. The boxes around these elements stay where they are, and so does this text.

A layout-shift observer must therefore stay silent on this page for as long as it is open.
