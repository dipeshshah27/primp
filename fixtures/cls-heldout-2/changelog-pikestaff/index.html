Changelog

Every release of the Pikestaff task runner, newest first.

3.2.010 March 2026
Latest
  • AddedRemote cache: share task outputs between machines with pikestaff cache --remote.
  • Added--affected now understands workspace protocol ranges.
  • ChangedThe default concurrency is the number of performance cores, not all cores.
  • FixedWatch mode no longer restarts twice when a config file is saved.
3.1.424 February 2026
  • FixedWindows: paths with spaces are quoted when a task is run through cmd.exe.
  • FixedOutput of failed tasks is printed even with --quiet.
